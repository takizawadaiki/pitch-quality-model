Baseball research · Statcast 2021–2026

Does pitch shape predict next season?

A pitcher’s results over one season are noisy. This project rates every pitch using only how it leaves the hand, with no results and no location, then asks whether that rating says something about the following season that the results do not.

01 /The designFixed before any real data was run

Learn from the past. Judge on the future.

The model never sees the seasons it is judged on. It learns what pitch shapes were worth, rates a later season, and those ratings are compared with what the same pitchers did the year after.

06 /Reading it honestlyGuards and limits

How the code guards against fooling itself

  • No training on the future. Seasons are ordered in one file, training checks it, and a test checks the model report.
  • No results in the inputs. A test scrambles every outcome column and requires the model inputs to stay identical.
  • Handedness. A test builds a mirror-image left- and right-hander and requires identical inputs.
  • Sign of run value. The run stops unless strikeouts lower run expectancy and home runs raise it.
  • Noise. Every headline number carries a 95% interval from resampling pitchers.

Limits

  • Stuff, not command. The model does not see location.
  • Count. The run value of a pitch depends on the count, which the model is not told.
  • Selection. Pitchers who throw 500 pitches in consecutive seasons are a healthier, better group.
  • Fitting noise.
  • Benchmark. ERA and FIP need earned runs and innings, which pitch data lacks. The comparison uses strikeout-minus-walk rate, FIP’s components per batter and expected wOBA.

Terms

Rating
The model’s expected runs prevented per 100 pitches from pitch shape, rescaled so 100 is average.
Expected wOBA allowed
How much damage hitters should have done given how hard and at what angle they hit the ball. Lower is better for the pitcher.
Strikeout-minus-walk rate
Strikeouts minus unintentional walks, per batter faced. Higher is better.
Runs prevented per 100 pitches
The actual change in run expectancy on a pitcher’s pitches, from his side. Higher is better.
